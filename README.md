This application backs the Stocxplorer Website, which is a gateway to smarter investments. The application is built with Python Flask, HTML and Javascript.

The main page invites the user to enter a Stock Ticker and Time Period to learn more about a Stock's performance. 
Users can search for stock tickers by entering the company name, using the search functionality.
The second page displays daily opening and closing values and other statistics, in addition to key Company Metrics. 
Each of the metric definition is displayed upon hovering on the Metric Name. A Chatbot on this page offers an
interactive experience to a user that has more questions.
