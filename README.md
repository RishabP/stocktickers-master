Stock Crisis Performance Analyzer

An analytical tool to evaluate corporate financial health and stock resilience during macroeconomic shocks. This application retrieves stock fundamentals, runs historical backtests, and benchmarks equity performance against predefined global crisis periods.

🚀 Key Features

Ticker Fundamentals: Fetches core financial metrics for any given stock ticker.
Historical Benchmarking: Includes a curated list of major global crisis periods.
Algorithmic Backtesting: Simulates historical trading strategies and risk scenarios across different market environments.
Impact Reporting: Generates comprehensive performance breakdowns for selected downturns.
Data Visualization: Provides clear insights into capital preservation and recovery speeds.
